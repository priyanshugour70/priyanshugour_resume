\subsection{{Multi-Provider Payment Gateway System \hfill 12/2024}}
\subtext{Technologies: Java, Spring Boot, Spring Cloud, PostgreSQL, Kafka, Redis, API Gateway, REST API, AWS (EC2, S3, RDS, Lambda), Docker }
\begin{zitemize}
    \item Built unified payment gateway for Stripe, Reserve Pay, and PayPal for cross-border transactions via one merchant integration.
    \item Architected event-driven microservices using Kafka, Redis caching, and API Gateway for routing and security.
    \item Implemented payment lifecycle: initiation, checkout, refunds, receipts, email notifications, and dashboard analytics.
    \item Deployed system on AWS for global payment acceptance through a single API.
\end{zitemize}
