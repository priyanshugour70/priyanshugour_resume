\subsection{{Multi-Provider Payment Gateway System \hfill 12/2024}}
\subtext{Technologies: Java, Spring Boot, Spring Framework, Spring Cloud, JDBC, PostgreSQL, Apache Kafka, Redis, API Gateway, REST API, Microservices, AWS (EC2, S3, RDS, Lambda), Docker, Kubernetes \hfill AWS}
\begin{zitemize}
    \item Built unified payment gateway supporting Stripe, Reserve Pay, and PayPal to enable cross-border transactions and eliminate multiple provider integrations for merchants.
    \item Architected microservices with event-driven communication using Kafka for async processing, Redis for caching, and API Gateway for routing and security.
    \item Implemented payment lifecycle features including initiation, checkout, refunds, automated receipts, email notifications, and real-time dashboard analytics.
    \item Deployed production-ready system on AWS enabling global payment acceptance through single unified API, reducing integration complexity.
\end{zitemize}

\subsection{{Self-Hosted Custom Domain Mail Server \hfill 01/2025}}
\subtext{Technologies: Spring Boot, SMTP, IMAP, POP3, PostgreSQL, Redis, Docker, Kubernetes, AWS (EC2, S3, RDS), REST API, Message Queue, DNS Management, Security Protocols \hfill AWS}
\begin{zitemize}
    \item Developed self-hosted mail server enabling custom domain emails without expensive third-party plans, providing full infrastructure control and data privacy.
    \item Implemented SMTP, IMAP, and POP3 protocols with Spring Boot for message queuing, routing, and protocol handling.
    \item Built architecture using Spring Boot, PostgreSQL for metadata, Redis for caching, Docker for containerization, and AWS for deployment with security configurations.
    \item Created production-grade email alternative with secure authentication, spam filtering, and storage management, reducing operational costs.
\end{zitemize}
